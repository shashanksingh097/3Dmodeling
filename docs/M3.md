# M3, part 1: datums, part features and measuring

What this step adds, all as commands first (the GUI buttons only build and
run them). The reference is in LANGUAGE.md, sections 13 to 15.

| Area | Commands |
|------|----------|
| Datums | `PLANE` (world, point and normal, 3 points, on a face, offset, turned about an axis, mid-plane, across an edge), `AXIS` (world, point and direction, 2 points, edge, face, two planes), `POINT` (coordinates, vertex, centre, along an edge), `DATUM, DELETE`, `LIST, DATUMS`; queries `ORIGIN()`, `DIR()` |
| Work planes | `WORKPLANE, plane` puts primitives, curves, profiles and holes on any plane; `WORKPLANE, OFF` |
| Features | `HOLE` (through, blind, counterbore, countersink, drill point, any direction), `SPLIT` (by a plane or a body; keep both sides or one), `SHELL` (open at selected faces, or closed; in or out), `DRAFT` (about a neutral plane), `OFFSET` (round or sharp) |
| Measuring | `DIST`, `ANGLE`, `MASSPROP` (with density: kg and kg.mm2), `CLASH`, `GAP()`; `SECTION` view with red caps |
| GUI | Datums drawn see-through with labels, never in the way of a click. A Features toolbar: Plane, Work plane, Hole, Shell, Draft, Distance, Angle, Mass, Clash, Section |

## How it is built

* `core/datum.py`: a datum is a frame (origin, X, normal) with a kind and a
  name. Plain Python, no kernel. The model keeps datums and the work plane in
  its snapshots, so undo, redo and history edits treat them like bodies.
* `geometry/features.py`: the kernel work (hole tool by revolving its
  profile, splitter, thick solid, offset, draft) plus adapters that turn each
  kernel maker's own history into the "what became of this face" answers the
  ID system needs. That is why a shelled or drafted box keeps its face IDs.
* `commands/feature_handlers.py`, `commands/measure_handlers.py`: the
  commands. Every feature result is checked (valid, not empty, really
  changed); `SHELL` with a wall too thick says the thickest one that works.
* A body split in pieces: the piece that keeps the body's ID keeps the face
  IDs; a face cut in two keeps its ID on that piece, and the other half gets
  a new one, so no ID is ever shared.

## Changed behaviour

`HOLE` and `SECTION` are now built-in commands, so a macro can no longer use
those names. The example scripts that had a `hole` or `section` macro now
call it `drill` and `station`.

## Try it

```bash
python -m modeler run scripts/bracket_features.cmd
python -m modeler                       # then RUN, "scripts/bracket_features.cmd"
```

Then `SECTION, side` and `VIEW, FRONT` to look inside, `MASSPROP, housing, 2700`
for an aluminium part's mass, or change `WALL` in the Parameters panel.
